Privacy Policy — ANIDOC Documentary Bot

Last updated: October 29, 2026

1. Overview

ANIDOC Documentary Bot is a personal automation project that generates images using Cloudflare Workers AI and uploads the generated images to the owner's Google Drive.

2. Information and Data Usage

This project uses Google Drive authorization to upload generated images to the owner's designated Google Drive folder.

The project does not intentionally collect or sell personal information from other users.

3. Google Drive Access

Google Drive access is used only for the project's intended file-upload functionality. Generated images are uploaded to the owner's designated folder.

4. Data Sharing

The project does not intentionally sell or share personal information with third parties.

Cloudflare processes image-generation requests according to its applicable privacy policy and terms.

5. Data Security

Access credentials and tokens should be stored as GitHub Actions secrets and must not be committed to the public repository.

6. Contact

For questions about this project, please contact the project owner through the GitHub repository.
